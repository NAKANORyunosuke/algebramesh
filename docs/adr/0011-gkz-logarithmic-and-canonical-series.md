# ADR 0011: GKZ の対数項を含む級数解と canonical series への正規化

- 状態: 採用
- 日付: 2026-11-03
- 関連: [ADR 0007](0007-gkz-indicial-and-series.md), 設計書 §9.3 の第3段階

## 背景

ADR 0007 の `gkz.series` は, 重複度 1 の指数の Γ級数だけを返していた.
重複度 2 以上の指数は `logarithmic` と報告するだけで, 級数を計算しなかった.
また返す Γ級数が canonical series になっているか (他の指数の開始項を含まないか) は確かめていなかった.

## 決定

### 対数の表し方

対数を含む項は `c x^(v+u) l^(k)` と表す.
ここで `l^(k) = prod_i (log x_i)^(k_i) / k_i!` は divided power である.
JSON の `log_powers` が `k`, `coefficient` が `c` である.
表示用の `display` では `c / prod k_i!` を係数にして `log(x_i)^(k_i)` を掛けた形で書く.

`d_i (x^e l^(k)) = x^(e - e_i) (e_i l^(k) + l^(k - e_i))` なので, 正規順序の作用素は項ごとに閉じた形で作用する.
1 つの `L = d . log x` の冪ではなく座標ごとの冪で表すのは, 方向の違う解を足し引きでき, 正規化ができるようにするためである.

### 解の作り方 (driver, Macaulay2)

重複度 `m` の指数 `v` について, 方向 `d` (`ker_ZZ A` の整数ベクトル) に沿って指数をずらす (SST §3.5).

- 族: 指数 `v + e d` の Γ級数 `F(e) = sum_u c_u(e) x^(v+u) x^(e d)` は, 各 `e` で `H_A(beta)` の解である. したがって `e` で展開した各係数 `phi_b` も解である.
- 先頭: `phi_b` の `x^v` での部分は `(d . log x)^b / b!` である.
- 有界性: `c_u(e)` の `e = 0` での零点の位数は, 符号の変わる整数座標の数で決まる. `phi_b` に寄与する `u` は, 符号の変わり方ごとの有限個の多面体に入る. それらが `w . u <= order` で有界な間だけ `phi_b` を計算する.
- 極: `c_u(e)` の分母は, 負の整数座標が非負になる座標ごとに `e` の因子を 1 つ持ち, 分子は, 非負の整数座標が負になる座標ごとに 1 つ持つ. 分母の零点の位数が分子のものより大きい項 (`e = 0` での極) が計算範囲にある場合は, その方向を使わない. 大きくなければ, 分子と分母を共通の `e^s` で割ってから展開する (Issue #88).
- 方向: `d` は, 整数座標の集合 `Z` を小さい順に選び, `Z` 上で 0 になる kernel のベクトルを候補にする (最大 24 個). `Z` 上で 0 にすると, その座標の符号が変わらず, 多面体が有界になりやすい.
- 基底: Γ級数 (`phi_0`) から始め, 方向を順に試す. 先頭部分 `(d . log x)^b` がそれまでのものと一次独立になる `phi_b` を加え, `m` 個そろったら止める. 独立性は Macaulay2 で係数行列の rank から判定する.
- 不足: `m` 個そろわなければ, 見つかったものと不足の数 (`missing`) と理由を返す.

### 検算 (Rust)

各解を `GkzInput::check_series` で検算する. 条件は ADR 0007 と同じである.

- 形: 各項の `u` は `ker A` にあり, `u != 0` なら `w . u > 0` でなければならない.
- 先頭: 対数の次数 `b` の解では, 全項の対数の次数が `b` 以下で, `x^v` に次数 `b` の項がある. `b = 0` では `x^v` の係数が 1 である.
- Euler 作用素: 厳密に消えなければならない. 消えなければ driver の誤りとしてジョブを失敗させる.
- toric 作用素: 計算範囲だけで決まる係数がすべて 0 でなければならない. そうでなければ `not_a_solution` とする.

解の一次独立性は driver が先頭部分で保証し, Rust は確かめない.
独立でない解が混じっても, 誤った解を返すことにはならない (基底が小さく見えるだけである).

### canonical series への正規化 (Rust)

検算に通った各解について, 他の指数 `v_j` (`v_j - v` が `ker_ZZ A` にあり重みが `(0, order]`) を重みの小さい順に調べる (`GkzInput::normalize`).

- 調べるもの: 級数の `x^(v_j)` の部分 (`l^(k)` の多項式) を取り出す.
- 消せる場合: その部分が `v_j` の検算済みの解の先頭部分の一次結合なら, その結合の解に `x^(v_j - v)` を掛けて引く.
- 順序: 引いた解の他の項は重みが大きいので, 後の段階で前の部分が戻ることはない.
- 結果: 引いた後の級数を `canonical_terms` とし, もう一度 `check_series` で検算する. 引いたものを `normalization` に記録する.
- 消せない場合: `canonical: false` と理由を返す.

## 状態の表

| 場所 | 値 | 意味 |
|---|---|---|
| 重複度 1 の指数 | `verified_to_order`, `not_a_solution`, `unsupported` | ADR 0007 と同じ |
| 重複度 2 以上の指数 | `logarithmic` | `solutions` に解を並べる. `missing` が見つからなかった解の数, `reason` がその理由 |
| 各解 | `verified_to_order`, `not_a_solution` | 解ごとの検算の結果. `direction` は使った方向 (Γ級数は `null`) |
| 検算済みの解 | `canonical`, `normalization`, `canonical_terms` | 正規化の結果 |

## 制限

- `e = 0` で極を持つ摂動は扱わない. `e^p` を掛けてから展開する方法はあるが, 先頭の指数が変わる場合の扱いを決めていない.
- `phi_b` に寄与する `u` の多面体が `w . u <= order` で有界でなければ, その `b` 以上を使わない. 例: `A = [[1,1,1],[0,1,2]]`, `beta = (-1,-1)`, weight `(1,0,1)` では, `u = m (1,-2,1)` (`m < 0`) が下に有界でない多面体に入るので, 2 つ目の解が見つからない (`missing: 1`, 回帰試験 `gkz_series_unbounded_perturbation`).
- `phi_b` が `x^v` より下の項 (`u != 0`, `w . u <= 0`) を 0 でない係数で持てば, その `b` 以上を使わない (Issue #88 の review). `x^v` が先頭でない解は, 先頭の検算 (ADR 0007) に通らないからである. 例: `ker A` が `l = (1,1,1,1,-2,-2)` で張られ, weight の `w . l` が正のとき, 指数 `v + l` (`v = (0,0,-1,-1,0,0)`) を `l` の方向に摂動すると, `u = -l` に係数 1/4 の項が残る (回帰試験 `gkz_series_common_zero_of_order_two`).
- 1 つの方向の冪だけを使うので, 解の先頭部分が `(d . log x)^b` の形の和で書けない場合 (異なる方向の積が要る場合など) は, 基底がそろわないことがある.
- 解の空間の次元が重複度と等しいことは, regular holonomic な場合の結果 (SST 第2章) に頼っている. A が斉次でない場合は `parameters.homogeneous` を見て判断する.
